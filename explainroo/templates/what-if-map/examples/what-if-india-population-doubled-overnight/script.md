# What if India's population doubled overnight?

> Facts: India has about 1.4 billion people (UN World Population Prospects 2024) on about 3.3 million square kilometres, roughly 440 people per square kilometre. Double that is about 2.8 billion and nearly 900 per square kilometre. India plus China today is about 2.8 billion.

## story {transition=cut hold=1.2}
[loud]What if India woke up tomorrow with twice as many people?[/loud] [#p1] That's 2.8 billion. About as many as India and China have today, combined. [#p2] Same land. The number of people per square kilometre would jump from about 440 to nearly 900. [#p3] Food would go first. India would need twice the grain, twice the milk, twice the vegetables, starting the very next morning. [#p4] Then water. Many Indian cities already run short. Now every tap, every well, every tanker has twice as many hands reaching for it. [#p5] Trains, schools, hospitals, jobs. Every queue in the country would double in a single night. [#end] Nothing in India is built for twice the people. So what if India's population doubled overnight?
