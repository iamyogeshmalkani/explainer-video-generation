# What if India had no internet for seven days?

> Facts: none needed beyond everyday use. Brand names are spoken but not shown as logos.

## story {transition=cut hold=1.2}
[loud]What if India had no internet for seven days?[/loud] [#basics] Start with the basics. No WhatsApp, no {UPI|U P I}, no maps. You couldn't book a cab or order food. [#work] Then work. Millions of people work from cloud tools. Offices that depend on email and video calls would stop. [#school] Schools with online classes would close. [#shops] Small businesses that sell on Instagram or online stores would lose a full week of sales. [#hospitals] Hospitals, banks and airlines also depend on networks to run properly. A lot would slow down. [#end] We use the internet all day, without thinking. So what if India had no internet for seven days?
