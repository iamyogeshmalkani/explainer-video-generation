# 50 "What if ...?" map topics

Each one suits the `what-if-map` template: a group of countries or places on a map, a size comparison, a
number, a ranking and a twist ("However..."). Hooks are written as the opening line. **Research and source every
number before you use it**; none of the figures are in this list on purpose.

Map angle: what the camera shows and fills. Twist: the "However" beat.

## How to pick one

- Choose a topic where **one picture changes** (a fill, a join, a removal), not a list of facts.
- Make sure you can name a real source for the main number and the twist.
- Prefer topics with a clear "However", since that beat is what keeps people watching to the end.
- Run each through `TEMPLATE.md` before writing the script.
