# An API call, step by step

> Sample content for the template. Replace it with your own topic. Facts here: an API is the set of requests a program can make to another program; a request has a method (such as GET), an address (URL) and sometimes a body; the server checks who is asking, reads its database and answers with a status code (200 means success, 404 means not found) and the data.

[#s1] Every app you use talks to a server. [#s2] That conversation goes through an {API|A P I}. [#s3] An {API|A P I} is a menu of things you can ask for. [#s4] Your app is the client. [#s5] It sends a request: [#method] a method, [#address] an address, [#data] and sometimes data. [#s6] The server checks who you are. [#s7] Then it reads the database. [#s8] It sends back a response, [#status] with a status code [#body] and the data. [#s9] A {200|two hundred} means it worked. [#s10] A {404|four oh four} means it could not find what you asked for. [#s11] That is the whole loop. [#r] Request. [#c] Check. [#a] Answer.
