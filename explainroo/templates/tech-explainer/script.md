# API

> Sample content for the template. Replace it with your own topic. Facts here: API stands for Application Programming Interface; it is the set of requests one program can make to another; the term goes back to the 1960s, long before smartphones; a request has a method (such as GET), an address (URL) and sometimes a body; the server checks who is asking, reads its database and answers with a status code (200 means success, 404 means not found) and the data.
