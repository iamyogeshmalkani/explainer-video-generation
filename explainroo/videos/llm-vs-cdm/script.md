# LLM vs CDM

> Facts and sources. ScaleDown launched "Constrained Decoding Models (CDMs)" on 13 October 2026 (Advance Intelligence story of 2026-10-13; Exec Sum and OpenRouter posts; LangChain's partnership post). Three models: Classify (labels you define, returns probabilities), Extract (JSON with confidence scores) and Summarize (a short summary). ScaleDown says they read the input once, skip the token-by-token loop, and are 200x faster and 467x cheaper than LLM APIs (the baseline is not specified), at $0.05 per million input tokens. These are the vendor's own figures. Critics (ibl.ai analysis) say constrained decoding is an existing technique, that Summarize does generate text, and that a valid format is not a correct answer (the Chavan arXiv study: constrained decoding raised schema validity to 100%, but its reach ends where schema conformance ends). A large language model writes its answer one token at a time. The "use a CDM for narrow tasks" line is a fair summary of the critics' guidance, not ScaleDown's claim.
